<p data-model-intro>LLM은 입력으로 <strong>다음 토큰의 확률</strong>을 계산합니다. 하나를 붙이면, 늘어난 입력으로 다시 계산합니다.</p>

<Expand id="lesson-model-scope" summary="이 작은 모형의 범위">

두 입력과 고정 계수로 직접 계산하는 설명용 모형입니다. 위치 계산은 생략하고, 앞의 자리와 자기 자신만 참고합니다. 실제 LLM은 많은 글에서 예측 오류를 줄이도록 계수를 배웁니다.
토큰은 글의 조각이며 단어 전체 또는 일부일 수 있습니다. 끝 표시는 종료용 토큰입니다. 높은 확률이 내용의 사실성을 보장하지는 않습니다.

</Expand>

<Expand id="math-conditional" summary="이 확률은 어떤 문맥의 값인가요?">

P(끝 \| 나는 학교에)의 세로선 뒤는 지금 주어진 입력, 앞은 다음 후보입니다. 입력이 바뀌면 같은 계수로도 확률이 바뀝니다.

</Expand>

<Expand id="table-generation" summary="선택: 확률표 선택 규칙 실습 열기">

정한 확률표의 선택 규칙 실습은 <a href={docHref('ko', 'exercises/next-token')}>별도 실습 페이지</a>에서 엽니다.

</Expand>

<Section id="tokens" locale="ko">
<span id="주어진-두-조각을-숫자로-찾기" class="lesson-anchor" aria-hidden="true"></span>

<div data-main-lesson>

각 토큰의 번호(ID)로 embedding 표에서 숫자 한 줄을 찾습니다. 이 숫자 줄을 <strong>벡터</strong>라고 부릅니다.

<LessonComputation locale="ko" stage="tokens" />

<Expand id="math-shape" summary="2 × 4: 어느 쪽이 토큰 수인가요?">

먼저 적은 2는 토큰 두 개의 행 수입니다. 뒤의 4는 각 토큰을 표현하는 값의 개수입니다. ID 1 하나와 그 행의 네 값은 같은 종류의 숫자가 아닙니다.

</Expand>

</div>

<Note variant="limit" title="이해를 돕기 위해 정한 예시 값입니다">

</Note>

<div data-main-lesson>

### 입력의 네 값을 비교하기 좋은 두 값으로 바꾸기

문맥을 참고하려면 현재 자리와 각 참고 자리를 비교할 숫자가 필요합니다. <strong>학교에의 입력 (0, 1, 0, 1)</strong>에서 시작합니다.
고정 계수를 각 입력값에 곱해 더하면 새 값 하나가 됩니다. 이를 출력마다 반복하는 것이 행렬곱입니다.

<LessonComputation locale="ko" stage="projection" />

<div id="similarity">

### 방금 만든 두 값으로 같은 자리끼리 비교하기

현재 자리의 기준은 <strong>(0, 2)</strong>입니다. 참고할 나는의 숫자 <strong>(0, 2)</strong>, 학교에의 숫자 <strong>(2, 0)</strong>에 각각 같은 자리끼리 곱해 더합니다.

<LessonComputation locale="ko" stage="comparison" />

### 같은 내적을 행 × 열로 놓기

한 쌍의 비교는 그대로 두고, 참고할 오른쪽 줄만 열로 놓습니다. 그 줄을 옆에 더 늘리면 현재 기준 하나로 여러 자리를 비교할 수 있습니다.

<LessonComputation locale="ko" stage="scores" />

</div>

### 비교 점수에서 참고 비중으로

앞에서 넘긴 <strong>(4, 0)</strong>으로 어느 입력 자리의 내용을 얼마나 가져올지 정합니다. 점수 두 개를 합이 1인 비중으로 바꾸는 계산이 <strong>softmax</strong>입니다.

<Section id="attention" locale="ko">
<span id="이미-해-본-계산에-q--k--v라는-이름-붙이기" class="lesson-anchor" aria-hidden="true"></span>

<div data-main-lesson>

현재 자리에서 비교할 기준이 <strong>Q</strong>, 참고할 자리의 비교 숫자가 <strong>K</strong>, 가져올 내용이 <strong>V</strong>입니다.
같은 입력에서 계수 세 벌로 만든 이 숫자들을, 방금 한 비교 → 참고 비중 → 내용 모으기 순서로 사용합니다.

<LessonComputation locale="ko" stage="attention" />

한 문장 안의 자리끼리 내용을 모으므로 <strong>self-attention</strong>이라고 부릅니다. 출력 행은 계속 학교에 자리에 대응합니다.
이 한 갈래의 결과를 다른 갈래와 합치기 전에, 지금 볼 수 있는 입력의 범위를 확인합니다.

</div>

<Section id="blocks" locale="ko">

<div data-main-lesson>

### 원래 입력을 더해 보존하기

attention 출력만 넘기면 원래 입력의 정보가 사라질 수 있습니다. 같은 칸끼리 원래 입력을 더하는 길을 <strong>잔차 연결(residual)</strong>이라고 부릅니다.
그다음 한 토큰의 값 크기를 정리하는 층 정규화를 합니다.

<LessonComputation locale="ko" stage="residual" />

### 방금 정규화한 값을 토큰 안에서 바꾸기

토큰 사이의 정보는 이미 attention으로 모았습니다. 이제 토큰 하나의 네 값을 넓혔다가 다시 좁히는 <strong>FFN</strong>으로 바꿉니다.
입력은 직전 정규화의 출력이며, 음수를 0으로 만드는 연산이 ReLU입니다.

<LessonComputation locale="ko" stage="feed-forward" />

### 다시 더하고 정규화하기

FFN에 들어간 행과 FFN에서 나온 행을 더하고, 다시 정규화합니다. 이 결과가 다음 후보의 점수를 만들 <strong>학교에 자리의 마지막 표현</strong>입니다.

<LessonComputation locale="ko" stage="readout" />

가장 큰 확률은 <strong>갔다 71.8%</strong>입니다. 입력은 여전히 나는 / 학교에 두 조각이며, 갔다는 다음에 고를 후보입니다.
학습에서는 이 예측을 정답과 비교하고, 생성에서는 이 확률에서 조각 하나를 골라 붙입니다.

attention의 비중 두 개는 이미 주어진 입력 두 자리에서 내용을 가져오는 몫입니다. 여기의 확률 네 개는 다음에 고를 어휘 네 후보의 몫입니다. 어휘 출력 계수가 마지막 표현을 후보별 점수로 바꿉니다.
